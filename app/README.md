# Sri Nidhi Flutter client

V0.1 provides authentication, verified branch selection and an adaptive store workspace.

Read the [project overview](../README.md), [local setup](../docs/deployment/local-setup.md), and [verification report](../docs/testing/v0.1-verification.md). Use Flutter 3.47.5 and the committed dependency lockfile.

Copy `config.example.json` to ignored `config.local.json` and use public development Supabase configuration. Without configuration the app opens the administrator setup screen. Synthetic store fixtures exist only in tests.
